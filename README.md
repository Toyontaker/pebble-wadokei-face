# Wadokei — 和時計（不定時法）の Pebble ウォッチフェイス

日の出から日の入りまでの昼と、日の入りから翌朝の日の出までの夜を、それぞれ六等分して「刻」を数える江戸時代の時刻法（不定時法）で時を示すウォッチフェイスです。
「明け六つ」「昼九つ」「暮れ六つ」「夜九つ」などの刻と干支（卯の刻、酉の刻…）を表示します。

緯度・経度から毎日、腕時計の上で日の出・日の入りを計算するため、一刻の長さは季節と場所によって伸び縮みします。東京では夏至の昼の一刻が約146分、夜が約94分、冬至では昼が約97分、夜が約143分になります。

文字盤のデザインは JR Mobley さんの [Horizon Watch Face](https://github.com/jrmobley/horizon-watchface) を元にしています。

## 文字盤の見方

- 外周は24時間で一周する太陽の軌道です。南中（真昼）が真上、真夜中が真下に来るよう毎日回します。
- 太陽の向きは見上げた空と同じです。北半球（南を向いて空を見る）では左から昇って右へ沈む時計回り、南半球（北を向く）では右から昇って左へ沈む反時計回りになります。緯度の正負で自動的に切り替わります（設定でオフにすると常に時計回り）。
- 日の出と日の入りを結ぶ線が地平線で、上が空（昼）、下が地（夜）です。
- 外周の丸が刻の境目で、刻の数（九・八・七・六・五・四）が入っています。黒い丸が明け六つ・暮れ六つ。丸と丸の間の点が「半」です（四つに分ける設定では、一刻の中に点が三つ並び、真ん中の大きい点が半）。十二支で呼ぶ設定では、丸の字が数の代わりに十二支（卯・辰…）になります。昼の刻は間隔が広く、夜の刻は狭い（冬は逆）のが、そのまま一刻の長さです。
- 赤い丸が今の太陽の位置、橙の帯が今いる刻です。
- 中央は上から、もう一方の呼び方（小さく）、刻の名（筆文字）、今の時刻、今の一刻の長さです。

| 呼び方 | 分け方 | 刻の名（大） | 上の小さい字 |
|---|---|---|---|
| 数（既定） | 二つ（既定） | 暮れ六つ / 暮れ六つ半 | 酉の刻 |
| 数 | 四つ | 暮れ六つ / 暮れ六つ半 | 酉一つ〜酉四つ |
| 十二支 | 二つ | 酉の刻 / 酉の刻半 | 暮れ六つ / 暮れ六つ半 |
| 十二支 | 四つ | 丑一つ〜丑四つ（丑三つ時の数え方） | 夜八つ / 夜八つ半 |
- 長方形の画面では、四隅に日付・曜日と、今日の昼・夜それぞれの一刻の長さを出します。
- 画面の下に通知（Timeline Quick View）が出ている間は、文字盤を縮めずに上へ寄せ、四隅の表示を消します。丸い画面では中央の文字を見える範囲に詰めます。

| 刻 | 干支 | | 刻 | 干支 |
|---|---|---|---|---|
| 明け六つ | 卯 | | 暮れ六つ | 酉 |
| 朝五つ | 辰 | | 宵五つ | 戌 |
| 昼四つ | 巳 | | 夜四つ | 亥 |
| 昼九つ | 午 | | 夜九つ | 子 |
| 昼八つ | 未 | | 夜八つ | 丑 |

## 設定

| 項目 | 内容 |
|---|---|
| 刻の呼び方 | 数で呼ぶ（明け六つ・暮れ六つ、既定） / 十二支で呼ぶ（卯の刻・酉の刻） |
| 刻の分け方 | 二つ（「半」、既定） / 四つ（「一つ」〜「四つ」。丑三つ） |
| 昼と夜の境目 | 日の出・日の入り（既定） / 江戸の暦法 |
| スマホの位置情報を使う | オン（既定）でスマホの現在地。オフのときは下の緯度・経度 |
| 緯度・経度 | 手動のときの場所。初期値は東京 |
| 南半球では右から左へ動かす | オン（既定）で、緯度がマイナスのとき文字盤を反時計回りにする。オフで常に時計回り |

「江戸の暦法」は、寛政暦以降の定義にならって、太陽が地平線の下 7°21′40″ にある時（日の出の約36分前、日の入りの約36分後。「手のひらの筋が見える」明るさ）を明け六つ・暮れ六つとします。昼の一刻がその分長くなります。このときも地平線（空と地の境）は実際の日の出・日の入りの位置に引くので、黒い六つの丸が地平線の下に来ます。

## 計算

- 日の出・日の入りは NOAA の簡略式（均時差と赤緯の級数）で求め、腕時計に libm が無いため三角関数は Pebble の整数テーブル（`sin_lookup` / `atan2_lookup`）で代用しています。国立天文台の暦と比べて東京で1〜3分の差です（`test/test_sun.c`）。
- 夜の刻は「今日の暮れ六つ〜明日の明け六つ」（日付が変わった後は「昨日の暮れ六つ〜今日の明け六つ」）を六等分しています。前後の日の日の出・日の入りも計算するので、日付をまたいでも刻はずれません。
- 白夜・極夜では昼か夜が消えるため、最短でも一刻1分を残して計算が破綻しないようにしています（表示の意味は薄れます）。
- 位置情報はスマホから受け取ると腕時計に保存され、以後はスマホ未接続でも毎日計算し直します。受け取る前は東京で計算します。

## ビルド

```
cd ~/wadokei-face
npm install        # @rebble/clay
pebble build
pebble install --phone <スマホのIP>
```

対応機種: basalt / chalk / diorite / emery / flint / gabbro（Pebble Time 系、Pebble 2、Time 2、Pebble 2 Duo、Round 2）。
設定画面は flint / gabbro に対応した @rebble/clay で作っています。スマホの言語が日本語なら日本語、それ以外は英語で表示します（`src/pkjs/config.js`）。

日本語はアプリにフォントを同梱しているので、言語パックが無くても表示できます（必要な字だけを `characterRegex` で切り出しています）。

### スクリーンショット

```
WADOKEI_DEMO="171,1215" pebble build                        # 夏至（通日171）の 20:15 に固定
test/qemu_shot.sh basalt screenshots/basalt_summer.png /tmp/wadokei-emu

WADOKEI_DEMO="284,330,edo" pebble build                     # 10/12 の 5:30、江戸の暦法
test/qemu_shot.sh chalk screenshots/chalk_edo.png /tmp/wadokei-emu
```

`WADOKEI_DEMO="通日,分[,edo][,eto][,q]"` を付けてビルドすると、日付・時刻・時差（日本時間）を固定します。`edo` は江戸の暦法、`eto` は十二支で呼ぶ、`q` は四つに分ける設定です。さらに `WADOKEI_PLACE="緯度,経度,時差"`（緯度・経度は 1e-4 度単位、時差は分）で場所も固定できます。例：シドニーの夏至（12/22）20:15 は `WADOKEI_DEMO="355,1215" WADOKEI_PLACE="-338688,1512093,660" pebble build`。撮り終えたら `pebble build` で通常のビルドに戻してください。

`test/qemu_shot.sh` は SDK 4.33 以降（qemu-pebble 7 以降）用です。`QUICKVIEW=1` を付けると、画面下に通知を出した状態で撮ります。SDK 付属のまっさらなフラッシュを作業ディレクトリに展開して qemu を直接起動するので、普段使いのエミュレータ（言語パックなど）には触れません。スマホ側の JS は動かないため、設定は送られず既定（東京）で表示されます。`test/shots.sh` は通常の `pebble install --emulator` を使う版です（JS が動き、保存された設定で上書きされます）。

### 計算のテスト

```
gcc -DSUN_HOST_TEST -Itest -o /tmp/test_sun test/test_sun.c src/c/sun.c src/c/wadokei.c -lm && /tmp/test_sun
```

## ファイル構成

```
src/c/main.c      文字盤の描画、設定と位置の受け取り
src/c/sun.c       日の出・日の入り・南中の計算
src/c/wadokei.c   不定時法（刻の境目、今の刻、刻の名と干支）
src/pkjs/         位置情報の取得と設定画面（Clay、日本語・英語）
test/             計算のテスト、スクリーンショット用スクリプト
tools/make_icon.py  アイコンの生成（store/ とメニュー用）
store/            ストア用アイコン
STORE.md          ストア掲載用の説明文（日本語・英語、ライセンス表記）
```
